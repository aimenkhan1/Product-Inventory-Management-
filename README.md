# Product-Inventory-Management-
A simple web app for small businesses to manage their product stock. Built with PHP and MySQL, it lets you add, view, update, and delete products while showing low stock alerts.

Features

Add Products: Name, category, price, quantity.

View Inventory: See all products with “Low Stock” warnings for quantities under 10.

Update Products: Edit category, price, or quantity.

Delete Products: Remove discontinued items.

Setup

Import the provided inventory_db SQL dump into phpMyAdmin or MySQL.

Update connection.php with your database credentials.

Open entry.php in your browser to start adding products.

View inventory at details.php.

Tech Stack

PHP 8

MySQL 

HTML / CSS

PDO for secure database queries
